## 1. 你会拿到什么

发布目录 `版本0.0.1/` 里有两个交付形态：

| 目录 | 文件 | 大小 | 说明 |
|---|---|---|---|
| `安装包/` | `智语言开发套件0.0.1.exe` | 约 196 MB | **安装程序**：双击 → 选安装目录 → 装出完整套件（第 5 章） |
| `便携版/` | `智语言开发套件0.0.1-windows-x64.zip`、`.zip.sha256` | 约 195 MB | **完整套件压缩包**：解压即用，也可用一条命令安装到系统（第 4 章） |
| `校验/` | `SHA256SUMS` | 1 KB | 上面所有文件的 SHA-256 汇总（安全校验用） |

两个形态装出来的**目录结构完全一样**（版本管理器/ 与 版本0.0.1/…，见 4.2 节）：安装程序内部就是把同一份便携版 ZIP 解压到你选的目录，再写好 `全局.配置`。
区别只在于：**安装包一条命令都不用敲**（推荐给"就想装上用"的人），**便携版可以先解压试跑再决定装不装**。

> 命名规则（规范 6.1.6）：压缩包带平台后缀 `-windows-x64`；**安装程序不带平台后缀**，因为它本身就是一个平台专有的可执行文件。

**校验和（0.0.1）**

```
安装包 exe : 87f9186ab9cf32cf09c063c248cf5ac76618e4f1d84cf7f5e4de69dfd427a29e
便携版 zip : ecb01ece7bb4344139af4f6c0c5b8c276461e1b72afc5d03b0589201935ee0ed
```

## 2. 两种形态怎么选

| 你的需求 | 选哪个 | 怎么做 |
|---|---|---|
| 我只想装上就能用，不敲命令 | **安装包** | 双击 `智语言开发套件0.0.1.exe` → 选目录 → 回车（第 5 章） |
| 我要在命令行任何地方敲 `智语言` | **安装包** 或 **便携版 + 安装命令** | 装完把 `<安装目录>\版本管理器` 加入 PATH（第 6 章） |
| 我要做正式项目（多文件、依赖库、测试） | 两个都行 | 装完用 `智语言 创建/运行/测试/构建` |
| 我要把程序编译成独立 `.exe` 发给别人 | 两个都行，但**需本机有 Rust** | 见第 13 章 |
| 我机器上不能装任何东西（免安装试跑） | **便携版（只解压不安装）** | 解压后直接运行 `版本0.0.1\执行文件\智语言.exe`（第 4.2 节） |

> **一句话区别**：安装包 = 「解压便携版 + 写全局配置」的自动化外壳，装完得到的就是便携版的目录；便携版 = 你自己解压，想装再敲一条 `安装` 命令（第 4.4 节）。

## 3. 三分钟快速开始

### 3.1 双击安装，然后跑一个脚本（约 2 分钟）

双击 `安装包\智语言开发套件0.0.1.exe`，会弹出安装窗口（不弹黑框控制台）：

```
┌ 智语言开发套件 0.0.1 安装程序 ─────────────────────────┐
│ 选择安装目录，然后点击「安装」。安装完成后，把 版本管理器   │
│ 目录加入 PATH 即可在任意位置使用 智语言 命令。            │
│                                                        │
│ 安装目录：                                              │
│ [ C:\Users\<你>\AppData\Local\Programs\智语言 ] [浏览…] │
│                                                        │
│ [==================== 进度条 ====================]      │
│ 准备就绪                                                │
│                                        [ 安装 ] [ 取消 ] │
└────────────────────────────────────────────────────────┘
```

点「浏览…」可以选任意目录，也可以直接改输入框里的路径。点「安装」后进度条走完，按钮变成「完成」，状态栏给出 PATH 提示。全程无需命令行。

装完验证（未配 PATH 也能用绝对路径）：

```bat
"%LOCALAPPDATA%\Programs\智语言\版本管理器\智语言.exe" 版本
```

期望输出：

```
0.0.1
```

写一个 `你好.智`：

```智语言
启动程序():
    输出("你好，智语言！")
结束
```

运行它：

```bat
"%LOCALAPPDATA%\Programs\智语言\版本管理器\智语言.exe" 运行 你好.智
```

期望输出：

```
[智语言] 字节码：C:\Users\<你的用户名>\AppData\Local\.智语言\产出\字节码文件\你好.字节码
你好，智语言！
```

### 3.2 想全局使用 `智语言` 命令（5 分钟）

1. 解压便携版 zip（第 4.2 节）；
2. 在解压目录执行安装命令（第 4.4 节）：
   ```bat
   版本管理器\智语言.exe 安装 "D:\下载\智语言开发套件0.0.1-windows-x64.zip"
   ```
3. 把 `%LOCALAPPDATA%\Programs\智语言\版本管理器` 加入 PATH（第 6 章）；
4. 新开一个命令行窗口，验证：
   ```bat
   智语言 版本
   ```

### 3.3 验证安装成功（四项）

```bat
智语言 版本         :: 期望：0.0.1
智语言 已安装       :: 期望：* 0.0.1 （当前激活）
智语言 诊断         :: 期望：安装路径 (存在)、已安装版本 0.0.1、默认版本 0.0.1
智语言 运行 你好.智  :: 期望：输出你写的内容（解释模式，开箱即用）
```

四项全过 = 装好了。没过的对照第 7 章的自检清单；想直接看能写出什么效果，跳到第 8 章的 8 个案例。

## 4. 便携版：解压与安装（推荐）

### 4.1 先校验文件完整性（可选但建议）

Windows（PowerShell）：

```powershell
Get-FileHash .\智语言开发套件0.0.1-windows-x64.zip -Algorithm SHA256
```

macOS / Linux：

```bash
shasum -a 256 智语言开发套件0.0.1-windows-x64.zip   # macOS
sha256sum 智语言开发套件0.0.1-windows-x64.zip       # Linux
```

结果应与第 1 章的 `ecb01ece7bb43441…` 一致；也可直接对照包内的 `…zip.sha256`。

### 4.2 解压

- Windows：右键 zip → **全部解压缩**（或用 7-Zip / WinRAR）。**注意：必须真正解压**，不要在压缩包里直接双击运行。
- macOS：双击 zip，得到文件夹 `智语言`。
- Linux：`unzip 智语言开发套件0.0.1-windows-x64.zip`

压缩包**自带一层顶层目录 `智语言/`**，所以解压到哪儿都会得到一个名为 `智语言` 的文件夹（和本文档里所有目录树的顶层一致）。

解压后的目录结构（= 安装后的布局）：

```
智语言/
├─ 版本管理器/
│  ├─ 智语言.exe          ← 版本管理器（命令入口，负责选择版本）
│  └─ 版本.文档
└─ 版本0.0.1/
   ├─ 执行文件/
   │  ├─ 智语言.exe        ← 工具包本体
   │  ├─ 智语言-编辑器服务.exe
   │  ├─ base.lib          ← 编译模式必需的运行时静态库
   │  └─ .base_build_fingerprint
   ├─ 标准库/              ← 8 个 .智 门面文件（查阅 API 用）
   ├─ 工具链/              ← clang + llvm-ar + clang 头文件（FFI 外部 C 用）
   └─ 许可证.文档
```

### 4.3 方式 A：不安装，直接用（绿色便携）

不写任何系统目录，直接从解压目录运行：

```bat
cd /d D:\智语言
版本0.0.1\执行文件\智语言.exe 版本
版本0.0.1\执行文件\智语言.exe 运行 D:\我的脚本\你好.智
```

- 优点：零安装、可放 U 盘；
- 缺点：每次都要写完整路径，不能用 `智语言` 短命令；
- 注意：`版本管理器\智语言.exe` 这个入口**需要已安装的版本**才能工作，未安装时请用 `版本0.0.1\执行文件\智语言.exe`。

### 4.4 方式 B：安装到系统（推荐，一条命令）

在**解压出来的 `智语言` 目录**里执行（把 zip 路径换成你自己的）：

```bat
版本管理器\智语言.exe 安装 "D:\下载\智语言开发套件0.0.1-windows-x64.zip"
```

也可以显式指定版本号，效果相同：

```bat
版本管理器\智语言.exe 安装 0.0.1 "D:\下载\智语言开发套件0.0.1-windows-x64.zip"
```

期望输出（实测）：

```
[智语言] 正在校验完整性…
[智语言] 校验通过
[智语言] 正在解压…
[智语言] 版本管理器已安装至：C:\Users\<用户名>\AppData\Local\Programs\智语言\版本管理器\智语言.exe
[智语言] 安装至：C:\Users\<用户名>\AppData\Local\Programs\智语言\版本0.0.1
[智语言] 已切换至 0.0.1
```

安装器行为说明：

- 版本号可省略——它会从 zip 内 `版本<号>/` 目录自动推断；
- 自动校验 zip 的 SHA-256（存在 `同名.zip.sha256` 时）；
- **已安装的同一版本不会被覆盖**，会提示 `版本0.0.1 已安装，不覆盖。`，需要先 `智语言 卸载 0.0.1`；
- 安装位置（默认）：

| 系统 | 安装路径 | 全局目录 |
|---|---|---|
| Windows | `%LOCALAPPDATA%\Programs\智语言` | `%LOCALAPPDATA%\.智语言` |
| macOS | `~/Library/Application Support/智语言` | `~/Library/Application Support/智语言` |
| Linux | `~/.local/bin/智语言` | `~/.智语言` |

> 如需装到别的位置：`智语言 安装 <绝对路径> "D:\包.zip"`。**务必写绝对路径**——相对路径会按"执行命令时的当前目录"解析，容易装到意想不到的地方。

### 4.5 安装后的目录

```
%LOCALAPPDATA%\Programs\智语言\
├─ 版本管理器\智语言.exe              ← 命令入口（放进 PATH 的就是这个目录）
└─ 版本0.0.1\
   ├─ 执行文件\{智语言.exe, 智语言-编辑器服务.exe, base.lib, .base_build_fingerprint}
   ├─ 标准库\  工具链\  许可证.文档
```

### 4.6 卸载 / 多版本

```bat
智语言 已安装            :: 列出所有已装版本（* 为当前激活）
智语言 切换 0.0.1         :: 切换默认版本
智语言 卸载 0.0.1         :: 卸载指定版本
智语言 卸载全部           :: 清空所有版本
```

## 5. 安装包：双击 → 选目录 → 安装

`安装包/` 里只有一个文件：**`智语言开发套件0.0.1.exe`（安装程序）**。它自身就带着整套载荷（约 196 MB），不需要旁边再放 `base.lib` 或 zip。

### 5.1 装什么、装到哪

双击运行后只有一件事要决定：**安装目录**。

| 做法 | 说明 |
|---|---|
| 直接用默认值 | 输入框预填 `%LOCALAPPDATA%\Programs\智语言`，点「安装」即可（不需要管理员权限） |
| 点「浏览…」 | 弹出文件夹选择框，选 D 盘、外置硬盘、任意目录都行 |
| 直接改输入框 | 也可以手工输入或粘贴路径 |

> 安装程序的窗口是 **Windows GUI 程序**（双击不会弹黑色控制台），解压在后台线程跑，进度条实时更新，窗口不会"未响应"。
> macOS / Linux 上仍是控制台向导（规范 6.1.5 的 `[1] 推荐 / [2] 系统 / [3] 自定义` 三选项），默认安装位置与便携版一致，见 14 章。

### 5.2 装完的目录（= 便携版解压结果）

便携版 zip 里那层 `智语言/` 就是这里的 `<你选的安装目录>`：安装程序把载荷剥掉外层后直接铺进去，所以选中 `D:\智语言` 得到的就是 `D:\智语言\版本管理器\…`。

```
<你选的安装目录>/
├─ 版本管理器/
│  ├─ 智语言.exe          ← 命令入口（负责选版本、转发命令）
│  └─ 版本.文档
└─ 版本0.0.1/
   ├─ 执行文件/
   │  ├─ 智语言.exe        ← 工具包本体
   │  ├─ 智语言-编辑器服务.exe
   │  ├─ base.lib          ← 编译模式必需的运行时静态库
   │  └─ .base_build_fingerprint
   ├─ 标准库/              ← 8 个 .智 门面文件（查阅 API 用）
   ├─ 工具链/              ← clang + llvm-ar + clang 头文件（FFI 外部 C 用）
   └─ 许可证.文档
```

安装程序还会顺手做两件事：把 `安装路径` / `开发套件版本` 写进 `全局.配置`（否则版本管理器不知道去哪找套件），并把包内 `base.lib` 与指纹一起落到 `执行文件/`（否则编译模式每次都要重建运行时库）。

### 5.3 静默安装（脚本）

带参数运行时**不弹窗口**，退化回命令行行为（输出仍可被父进程重定向捕获）：

```bat
:: 直接装到指定目录，不询问、不弹窗
智语言开发套件0.0.1.exe --目标 D:\智语言 --静默

:: 查看帮助（写标准输出）
智语言开发套件0.0.1.exe --帮助
```

`--静默` 不带 `--目标` 时，装到默认位置（`%LOCALAPPDATA%\Programs\智语言`）。
`--静默` 也不会追问"目录已有套件是否覆盖"，适合重复安装/重装。

### 5.4 卸载

安装程序不写注册表、不写开始菜单，**卸载 = 删目录 + 清配置**：

```bat
:: 1) 删套件目录（换成你的安装目录）
rmdir /s /q "%LOCALAPPDATA%\Programs\智语言"

:: 2) 删全局数据（字节码缓存、全局库；不需要可保留）
rmdir /s /q "%LOCALAPPDATA%\.智语言"
```

再手动把 PATH 里那条 `…\版本管理器` 删掉即可。也可以用 `智语言 卸载全部`（会删掉整个安装目录，需输入 `yes` 确认）。
完整步骤（含 PATH 精确删除、占用排查、卸载后核对）见 **第 15 章 卸载与彻底删除**。

### 5.5 与便携版的关系

安装程序内部就是把**同一份便携版 ZIP** 解压到你选的目录，再写配置——所以两者装出来逐文件一致，语言能力没有区别。想要「先解压试跑、确认没问题再安装」的人用便携版（第 4 章）。

## 6. 配置环境变量（PATH）

### 6.1 要加的到底是哪个目录

安装完有两个 exe，**PATH 里要加的是"版本管理器"那个目录**：

```
%LOCALAPPDATA%\Programs\智语言\
├─ 版本管理器\智语言.exe      ← 加这个目录！它负责选版本、转发命令
└─ 版本0.0.1\执行文件\智语言.exe  ← 不要加这个（跳过版本管理器，切版本会失效）
```

不配 PATH 也能用，但每次都要写完整路径：

```bat
C:\Users\me\AppData\Local\Programs\智语言\版本管理器\智语言.exe 运行 a.智
```

配好后任何目录都能直接敲：

```bat
智语言 运行 a.智
```

> 为什么必须用版本管理器：它按 `全局.配置` 里的"当前激活版本"去调用
> `版本0.0.1\执行文件\智语言.exe`。直接调执行文件能跑，但 `智语言 切换/回退` 就不起作用了。

### 6.2 Windows（三种方式任选）

**方式一：图形界面（推荐，永久生效）**

1. `Win + R` → 输入 `sysdm.cpl` → 回车；
2. 「高级」→「环境变量」；
3. 在「用户变量」里选中 `Path` →「编辑」→「新建」；
4. 粘贴（把 `<用户名>` 换成你的）：
   ```
   C:\Users\<用户名>\AppData\Local\Programs\智语言\版本管理器
   ```
5. 一路「确定」；
6. **关闭所有已打开的命令行窗口**，重新打开一个（PATH 改动只对新进程生效）。

**方式二：命令行（永久写入用户 PATH）**

```bat
setx PATH "%PATH%;%LOCALAPPDATA%\Programs\智语言\版本管理器"
```

> ⚠ `setx` 有 1024 字符上限，PATH 很长时可能被截断。更安全的写法是只追加：
> ```powershell
> [Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path","User") + ";$env:LOCALAPPDATA\Programs\智语言\版本管理器", "User")
> ```

**方式三：只在当前窗口临时生效（调试用）**


### 6.7 配 PATH 的 5 个坑

| 坑 | 表现 | 正确做法 |
|---|---|---|
| 改完没重开窗口 | 老窗口里仍报"不是内部或外部命令" | PATH 只对**新进程**生效，关掉**所有**命令行/IDE 终端再开 |
| 加错目录 | `智语言 切换` 无效、`智语言 版本` 报错 | 加 `…\版本管理器`，不是 `…\版本0.0.1\执行文件` |
| 用 `setx PATH "%PATH%;..."` 拼接 | PATH 被截断（1024 字符）或写成系统+用户混合 | 用 6.2 的图形界面，或 6.2 方式二的 PowerShell 增量写法 |
| 重复添加多次 | `where 智语言` 出来好几行 | 编辑 PATH，把重复行删掉只留一条 |
| 公司电脑 PATH 被策略锁定 | 改完重启又没了 | 让 IT 放开，或改用 6.6 的 `智语言.bat` 方案 |

## 8. 上手案例（8 个，逐个可跑）

每个案例都是**完整可运行**的文件，输出是本机实测结果。建议按顺序敲一遍，比读文档快得多。

先准备一个练习目录：

```bat
mkdir D:\智语言练习
cd /d D:\智语言练习
```

每个案例存成一个 `.智` 文件，用 `智语言 运行 文件名.智` 执行。

### 8.1 案例一：你好世界

`你好.智`：

```智语言
启动程序():
    输出("你好，智语言！")
结束
```

```bat
智语言 运行 你好.智
```

```
你好，智语言！
```

**要点**：每个程序都从 `启动程序()` 开始，`结束` 关闭代码块。中文标点、中文变量名都能用。

### 8.2 案例二：变量与类型

`变量.智`：

```智语言
启动程序():
    姓名 = "小明"
    年龄 = 18
    成绩 = 92.5
    是否成年 = 年龄 >= 18

    输出("姓名：" + 姓名)
    输出("年龄：" + 转文本(年龄))
    输出("成绩：" + 转文本(成绩))
    输出("是否成年：" + 转文本(是否成年))
结束
```

```
姓名：小明
年龄：18
成绩：92.5
是否成年：真
```

**要点**：
- 变量直接 `名字 = 值`，类型自动推断（`18` 是整数、`92.5` 是小数、`真/假` 是逻辑）；
- 文本拼接用 `+`，**非文本要先用 `转文本()`** 包起来，否则类型不匹配；
- `>=`、`==`、`!=` 返回逻辑值。

### 8.3 案例三：条件与循环

`循环.智`：

```智语言
启动程序():
    总数 = 0
    循环 计数 = 1, 计数 <= 10, 计数 += 1:
        如果 计数 % 2 == 0:
            总数 = 总数 + 计数
        结束
    结束
    输出("1~10 的偶数和 = " + 转文本(总数))
结束
```

```
1~10 的偶数和 = 30
```

**要点**：`循环 初值, 条件, 步进:` 是 C 风格三段式；`如果 … 结束` 可嵌套；`%` 是取余（数学非负余数）。

### 8.4 案例四：函数与递归

`递归.智`：

```智语言
阶乘(整数 数) 整数:
    如果 数 <= 1:
        返回 1
    结束
    返回 数 * 阶乘(数 - 1)
结束

启动程序():
    循环 序号 = 1, 序号 <= 6, 序号 += 1:
        输出(转文本(序号) + "! = " + 转文本(阶乘(序号)))
    结束
结束
```

```
1! = 1
2! = 2
3! = 6
4! = 24
5! = 120
6! = 720
```

**要点**：函数签名是 `名(类型 参数) 返回类型:`，形参必须写类型；有返回值要声明返回类型并用 `返回`。

### 8.5 案例五：数组与映射

`容器.智`：

```智语言
启动程序():
    科目 = ["语文", "数学", "英语"]
    分数 = [92, 88, 95]
    成绩 = {"语文": 92, "数学": 88, "英语": 95}

    输出("按位置遍历数组：")
    循环 序号 = 1, 序号 <= 科目.长度(), 序号 += 1:
        输出("  " + 科目[序号] + " = " + 转文本(分数[序号]))
    结束

    输出("按名字查映射：")
    输出("  数学 = " + 转文本(成绩.获取("数学")))
    如果 成绩.包含("物理"):
        输出("  物理 = " + 转文本(成绩.获取("物理")))
    否则:
        输出("  物理 = 没有这一科")
    结束

    总分 = 0
    循环 序号 = 1, 序号 <= 分数.长度(), 序号 += 1:
        总分 = 总分 + 分数[序号]
    结束
    输出("总分 = " + 转文本(总分))
结束
```

```
按位置遍历数组：
  语文 = 92
  数学 = 88
  英语 = 95
按名字查映射：
  数学 = 88
  物理 = 没有这一科
总分 = 275
```

**要点**：
- 数组下标**从 1 开始**（`科目[1]` 是"语文"），越界会抛异常；
- 映射用 `.获取(键)` 取值，键不存在返回**空值**（不会崩），所以先用 `.包含(键)` 判断；
- `.长度()` 对数组和映射都适用。

### 8.6 案例六：结构体与方法

`结构体.智`：

```智语言
结构体 矩形(宽=1.0, 高=1.0):
    小数 宽 = 宽
    小数 高 = 高

    面积() 小数:
        返回 宽 * 高
    结束

    缩放(小数 倍数) 矩形:
        返回 矩形(宽 * 倍数, 高 * 倍数)
    结束
结束

启动程序():
    甲 = 矩形(3.0, 4.0)
    输出("甲 面积 = " + 转文本(甲.面积()))

    乙 = 甲.缩放(2.0)
    输出("乙 面积 = " + 转文本(乙.面积()))
结束
```

```
甲 面积 = 12.0
乙 面积 = 48.0
```

**要点**：`结构体 名(构造参数=默认值):` 里先声明字段（`小数 宽 = 宽` 把参数写进字段），方法直接写 `名字(参数) 返回类型:`。

### 8.7 案例七：异常与始终

`异常.智`：

```智语言
启动程序():
    成功 = 假
    捕获:
        结果 = 10 / 0
        输出("这行不会执行")
    异常:
        成功 = 真
    始终:
        输出("始终块：不管成功还是异常都会执行")
    结束

    如果 成功:
        输出("除零已被捕获，程序继续运行")
    结束
结束
```

```
始终块：不管成功还是异常都会执行
除零已被捕获，程序继续运行
```

**要点**：`捕获 / 异常 / 始终 / 结束` 对应 try / catch / finally；`始终` 块无论正常还是异常都会执行，适合放清理代码。

### 8.8 案例八：写一个能"自动判定"的验证脚本

这是最实用的一节：让脚本自己告诉你**通过还是失败**，为将来接自动化做准备。

`验证.智`：

```智语言
阶乘(整数 数) 整数:
    如果 数 <= 1:
        返回 1
    结束
    返回 数 * 阶乘(数 - 1)
结束

// 传引用：函数内改的 失败数 会带回调用方
断言(文本 名称, 逻辑 条件, 传引用 整数 失败数):
    如果 条件:
        输出("  [通过] " + 名称)
    否则:
        输出("  [失败] " + 名称)
        失败数 = 失败数 + 1
    结束
结束

启动程序():
    失败数 = 0

    断言("阶乘(5) = 120", 阶乘(5) == 120, 失败数)
    断言("1 + 1 = 2", 1 + 1 == 2, 失败数)
    断言("数组长度 = 3", [1, 2, 3].长度() == 3, 失败数)
    断言("映射取值 = 1", {"甲": 1}.获取("甲") == 1, 失败数)

    如果 失败数 == 0:
        输出("全部通过")
    否则:
        输出("失败 " + 转文本(失败数) + " 项")
    结束
结束
```

```
  [通过] 阶乘(5) = 120
  [通过] 1 + 1 = 2
  [通过] 数组长度 = 3
  [通过] 映射取值 = 1
全部通过
```

**要点**：
- 断言封装成函数，`传引用` 让函数内的 `失败数` 改动能带回 `启动程序`（不加 `传引用` 就是值传递，外面看不到）；
- **最后一行就是结论**——`全部通过` 或 `失败 N 项`，人眼扫一行即可；
- 想让它变成"故意失败"看看效果？把 `1 + 1 == 2` 改成 `1 + 1 == 3` 再跑一次。

（在 `.bat` 文件里写要把 `%f` 写成 `%%f`。）

## 13. 编译模式（生成独立 exe）的环境要求

### 13.1 两个模式的区别

| 模式 | 命令 | 需要外部工具？ | 产物 |
|---|---|---|---|
| 解释模式 | `智语言 运行` | **不需要**，开箱即用 | 字节码缓存（内部用） |
| 编译模式 | `智语言 构建` / `构建运行` | **需要 Rust 工具链（MSVC）** 或 Visual Studio Build Tools | 独立 `.exe` |

### 13.2 环境要求

编译模式在链接阶段使用 **`rust-lld`**，并需要 Windows 系统导入库（`kernel32.lib`、`msvcrt.lib`、`ws2_32.lib` 等）。这些来自 **Rust 的 MSVC 工具链**（安装 rustup 时选择 `x86_64-pc-windows-msvc`）或 **Visual Studio Build Tools + Windows SDK**。

本套件已随包提供：`base.lib`（运行时静态库）、`clang.exe`/`llvm-ar.exe`（FFI 与外部 C 编译）。
**未随包**提供：`rust-lld` 与 Windows 系统导入库（许可与体积原因）。

检查是否具备：

```bat
rustc --version
```

有版本号（例如 `rustc 1.8x.x`）即具备；没有则：

1. 打开 <https://rustup.rs> 安装 rustup，默认工具链选 `x86_64-pc-windows-msvc`；
2. 若 rustup 提示缺少 C++ 生成工具，按提示安装 Visual Studio Build Tools（勾选「使用 C++ 的桌面开发」）。

### 13.3 报错对照表（实测文案）

| 报错 | 原因 | 处理 |
|---|---|---|
| `链接失败：找不到 rust-lld。请确保 Rust 工具链正确安装。` | 本机没有 Rust / rustc 不在 PATH | 按 11.2 安装 Rust；或改用解释模式 `运行` |
| `构建 基础功能 staticlib 失败: manifest path …\Cargo.toml does not exist` + 大量 `undefined symbol: 智语言_*` | `base.lib` 被删/被挪走（正常安装不会出现） | 从安装包重装，或在 exe 同目录放回 `base.lib` 与 `.base_build_fingerprint`；缺指纹时程序会尝试用 cargo 重建（无源码必然失败） |
| `链接失败…undefined symbol: 某外部库符号` | FFI 外部库路径未配置 | 在 `配置/项目依赖.配置` 的 `[外部语言…]` 段写 `路径`（见编程规范 §6.5） |

## 14. 目录与数据位置

| 内容 | Windows | macOS | Linux |
|---|---|---|---|
| 全局目录（配置/缓存/库） | `%LOCALAPPDATA%\.智语言` | `~/Library/Application Support/智语言` | `~/.智语言` |
| 安装路径（版本） | `%LOCALAPPDATA%\Programs\智语言` | `~/Library/Application Support/智语言` | `~/.local/bin/智语言` |
| 全局配置 | 全局目录`\配置\全局.配置` | 同左 | 同左 |

- 项目自己的产物在项目目录下 `产出/`；

## 15. 卸载与彻底删除

卸载要清的是**三样东西**，少清一样就会留残留（比如命令还在、缓存还占几百 MB）：

| 要清的 | 位置（Windows） | 不清会怎样 |
|---|---|---|
| ① 套件目录 | `%LOCALAPPDATA%\Programs\智语言` | 命令还能用；占 200 MB+ |
| ② PATH 条目 | 用户变量 `Path` 里那条 `…\版本管理器` | `where 智语言` 仍指向已删除的路径 |
| ③ 全局目录（可选） | `%LOCALAPPDATA%\.智语言` | 字节码缓存、全局库、配置继续占空间 |

> 安装程序**不写注册表、不写开始菜单、不注册服务**，所以"卸载"没有系统级残留，本质就是删目录 + 删 PATH。

### 15.1 Windows：命令卸载（推荐）

**只卸载某个旧版本**（多版本共存时）：

```bat
智语言 已安装          :: 先看有哪些版本，* 是当前激活
智语言 卸载 0.0.3      :: 卸载 0.0.3
```

> ⚠ 当前激活的那个版本**不能直接卸载**，会提示 `不能卸载当前激活版本 0.0.5，请先切换`。
> 只有一个版本时，请直接用下面的 `卸载全部`。

**全部卸载（连版本管理器一起删）**：

```bat
智语言 卸载全部
```

会提示 `警告：将删除所有开发套件版本及版本管理器！`，输入 `yes` 回车确认。取消就直接回车或输入别的。

### 15.2 Windows：不想用命令就手动删

1. **先关掉占用**：所有命令行窗口、VS Code（编辑器插件会拉起 `智语言-编辑器服务.exe`）、
   任务管理器里任何 `智语言*.exe` 进程；
2. 删套件目录（资源管理器里删，或命令行）：
   ```bat
   rmdir /s /q "%LOCALAPPDATA%\Programs\智语言"
   ```
3. 删 PATH 条目（15.3）；
4. 需要的话删全局目录：
   ```bat
   rmdir /s /q "%LOCALAPPDATA%\.智语言"
   ```

### 15.3 删掉 PATH 里的那条

**图形界面**：

1. `Win + R` → `sysdm.cpl` →「高级」→「环境变量」；
2. 「用户变量」里选中 `Path` →「编辑」；
3. 选中 `…\智语言\版本管理器` 那一行 →「删除」→ 一路「确定」；
4. **重开命令行窗口**。

**PowerShell（精确删除那一条，不影响其它 PATH）**：

```powershell
$目标 = "$env:LOCALAPPDATA\Programs\智语言\版本管理器"
$新 = ([Environment]::GetEnvironmentVariable("Path","User") -split ';' |
       Where-Object { $_ -and $_ -ne $目标 }) -join ';'
[Environment]::SetEnvironmentVariable("Path", $新, "User")
```

> 别用 `setx PATH "..."` 手工拼接，容易把 PATH 截断（1024 字符上限）或写重复。

### 15.4 全局目录删不删？

| 目录 | 内容 | 建议 |
|---|---|---|
| `%LOCALAPPDATA%\.智语言\产出\字节码文件` | 解释模式的字节码缓存 | **可以删**，下次运行自动重建 |
| `%LOCALAPPDATA%\.智语言\库` | 用 `智语言 库 安装` 装的全局库 | 还要用库就保留 |
| `%LOCALAPPDATA%\.智语言\配置\全局.配置` | 安装路径、镜像源、离线模式等 | 重装后想保留设置就留 |

只想清缓存、保留设置：

```bat
rmdir /s /q "%LOCALAPPDATA%\.智语言\产出"
```

### 15.5 macOS / Linux

```bash
# 1) 命令卸载（同上：激活版本要先切走；或直接卸载全部）
智语言 卸载全部

# 2) 或手动删目录
rm -rf "$HOME/Library/Application Support/智语言"     # macOS
rm -rf "$HOME/.local/bin/智语言"                       # Linux

# 3) 删 PATH 里那行（编辑 shell 配置，删掉含 智语言/版本管理器 的 export 行）
#    macOS: ~/.zshrc        Linux: ~/.bashrc
source ~/.zshrc    # 或 ~/.bashrc

# 4) 全局目录（可选）
rm -rf "$HOME/Library/Application Support/智语言"   # macOS 与安装目录同处
rm -rf "$HOME/.智语言"                                # Linux
```

### 15.6 卸载后核对（30 秒）

```bat
where 智语言
```

期望：**没有输出**（或提示"找不到文件"）——若还有输出，说明 PATH 里那条没删干净。

```bat
dir "%LOCALAPPDATA%\Programs\智语言"
```

期望：`系统找不到指定的路径`。

再重开一个窗口敲 `智语言 版本`，应提示"不是内部或外部命令"。

### 15.7 卸载不掉？多半是文件被占用

| 现象 | 原因 | 处理 |
|---|---|---|
| `拒绝访问` / `另一个程序正在使用此文件` | 有 `智语言*.exe` 在跑（编辑器插件、终端里的 REPL） | 关掉 VS Code 窗口、退出 REPL，任务管理器结束残留进程后重试 |
| `卸载失败: ...` 权限不足 | 装在 `C:\Program Files` | 用**管理员**身份打开终端再执行 |
| 提示"不能卸载当前激活版本" | 只剩一个版本 | 用 `智语言 卸载全部`，或删目录 |
| 卸载后命令还在 | PATH 没删 | 见 15.3，删完**必须重开窗口** |

## 16. 常见问题（FAQ）

**Q1：双击 exe 闪一下就没了？**
这是命令行程序，双击不带参数会只打印帮助/版本后退出。请在 `cmd` 或 PowerShell 里执行，或给快捷方式加参数。

**Q2：`智语言 版本` 提示“不是内部或外部命令”？**
PATH 没配好或没重开窗口。按第 6 章配置 → **关闭所有命令行窗口** → 重新打开 → `where 智语言` 确认。

**Q3：`智语言 版本` 输出空行或 0.0.1 之外的内容？**
`版本` 命令输出版本号；`智语言开发套件.exe 版本` 输出 `智语言开发套件 v0.0.1`。两者都对，前者是版本管理器，后者是本体。

**Q4：安装时提示「版本0.0.1 已安装，不覆盖。」**
安装器不覆盖已存在版本。先 `智语言 卸载 0.0.1`，再重新安装。

**Q5：SHA-256 校验失败 / 解压报错？**
文件下载不完整（尤其是 195 MB 的便携版）。重新下载并核对第 1 章哈希。

**Q6：`运行` 很好用，但 `构建` 失败？**
见第 13 章：编译模式需要 Rust/MSVC。纯学习与脚本自动化用 `运行` 即可。

**Q7：中文路径/中文文件名能用吗？**
可以。链接器走 UTF-16 API，专为中文路径设计；源文件名建议用中文或英文，不要用早期 GBK 编码的批处理去调用。

**Q8：换台电脑要重新装吗？**
`~/.智语言`（全局目录）可删可重建，不迁移也行；便携版解压到新机器后重新执行一次 `安装` 即可。项目目录（含 `配置/`）可以直接拷走。

**Q9：离线能用吗？**
能。解释/构建/测试/校验都不联网；只有 `库 安装`、`可安装`、`更新`、`自我更新` 等需要访问镜像源。离线时可 `智语言 设置 离线模式 真`。

**Q10：怎么彻底卸载？**
```bat
智语言 卸载全部
```
再删除 `%LOCALAPPDATA%\Programs\智语言` 与 `%LOCALAPPDATA%\.智语言`（后者含缓存、库、配置）。
